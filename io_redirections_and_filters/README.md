# alu-shell / io_redirections_and_filters

I/O redirections and filters exercises (tasks 0-26). Each file is a Bash script starting with `#!/bin/bash`.

| File | Description |
|---|---|
| 0-hello_world | Prints "Hello, World" |
| 1-confused_smiley | Prints a confused smiley |
| 2-hellofile | Displays /etc/passwd |
| 3-twofiles | Displays /etc/passwd and /etc/hosts |
| 4-lastlines | Last 10 lines of /etc/passwd |
| 5-firstlines | First 10 lines of /etc/passwd |
| 6-third_line | Third line of `iacta` (no sed) |
| 7-file | Creates the file with the tricky name containing "Best School" |
| 8-cwd_state | Writes `ls -la` output to `ls_cwd_content` |
| 9-duplicate_last_line | Duplicates the last line of `iacta` |
| 10-no_more_js | Deletes all `.js` regular files recursively |
| 11-directories | Counts directories and sub-directories |
| 12-newest_files | 10 newest files, newest first |
| 13-unique | Prints words appearing exactly once, sorted |
| 14-findthatword | Lines containing "root" in /etc/passwd |
| 15-countthatword | Number of lines containing "bin" |
| 16-whatsnext | Lines containing "root" plus 3 lines after |
| 17-hidethisword | Lines not containing "bin" |
| 18-letteronly | Lines of sshd_config starting with a letter |
| 19-AZ | Replaces A with Z and c with e |
| 20-hiago | Removes all c and C |
| 21-reverse | Reverses its input |
| 22-users_and_homes | Users and home directories, sorted |
| 23-empty_casks | Names of empty files and directories |
| 24-gifs | Names of `.gif` files without extension, sorted |
| 25-acrostic | Decodes first-letter acrostics |
| 26-the_biggest_fan | Top 11 hosts by number of requests in a TSV log |
