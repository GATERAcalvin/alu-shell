# alu-shell / init_files_variables_and_expansions

Shell init files, variables and expansions exercises (tasks 0-17). Each file is a Bash script starting with `#!/bin/bash`.

| File | Description |
|---|---|
| 0-alias | Creates the alias `ls` with value `rm *` |
| 1-hello_you | Prints `hello` followed by the current user |
| 2-path | Appends `/action` to the PATH |
| 3-paths | Counts the directories in the PATH |
| 4-global_variables | Lists environment variables |
| 5-local_variables | Lists all variables, environment variables and functions |
| 6-create_local_variable | Creates the local variable `BEST=School` |
| 7-create_global_variable | Creates the global variable `BEST=School` |
| 8-true_knowledge | Prints 128 + `TRUEKNOWLEDGE` |
| 9-divide_and_rule | Prints `POWER` / `DIVIDE` |
| 10-love_exponent_breath | Prints `BREATH` to the power `LOVE` |
| 11-binary_to_decimal | Converts `BINARY` from base 2 to base 10 |
| 12-combinations | Prints all two-letter combinations except `oo` |
| 13-print_float | Prints `NUM` with two decimal places |
| 14-decimal_to_hexadecimal | Converts `DECIMAL` from base 10 to base 16 |
| 15-rot13 | Encodes and decodes rot13 |
| 16-odd | Prints every other line, starting with the first |
| 17-water_and_stir | Adds `WATER` and `STIR` and prints the result in base bestchol |
