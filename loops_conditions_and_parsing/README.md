# alu-shell / loops_conditions_and_parsing

Loops, conditions and parsing exercises. Each file is a Bash script.

| File | Description |
|---|---|
| 1-for_best_school | Displays "Best School" 10 times, using a for loop |
| 2-while_best_school | Displays "Best School" 10 times, using a while loop |
| 3-until_best_school | Displays "Best School" 10 times, using an until loop |
| 4-if_9_say_hi | Displays "Best School" 10 times, "Hi" after the 9th |
| 5-4_bad_luck_8_is_your_chance | Loops 1 to 10, calling out lucky/unlucky numbers |
| 6-superstitious_numbers | Loops 1 to 20, calling out superstitious numbers with case |
| 7-clock | Displays hours 0-12 and minutes 1-59 |
| 8-for_ls | Lists the current directory, keeping text after the first dash |
| 9-to_file_or_not_to_file | Reports on the existence, emptiness and type of `school` |
| 10-fizzbuzz | Classic FizzBuzz from 1 to 100 |
| 11-read_and_cut | Prints username, uid and home directory from /etc/passwd |
| 12-tell_the_story_of_passwd | Tells a story for each /etc/passwd entry using IFS |
| 13-lets_parse_apache_logs | Prints IP and HTTP status code from apache-access.log |
| 14-dig_the-data | Groups visitors by IP and status code, sorted by occurrence |

`apache-access.log` is the log file used by tasks 13 and 14.
